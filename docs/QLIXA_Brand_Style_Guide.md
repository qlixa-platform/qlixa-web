# QLIXA Brand Style Guide
*Версія 1.0 — Липень 2026*

---

## 1. Хто ми

**Місія:**
QLIXA — твій спокійний цифровий помічник в Австрії, який допомагає розібратися з податками, бізнесом і папірцями без складних термінів, без паніки і без потреби бути бухгалтером.

**Три слова бренду:** Простий. Спокійний. Свій.

**Характер бренду:**
Молода подруга, яка сама колись дуже заплуталась в австрійських папірцях, довго розбиралась, але врешті-решт все зрозуміла. Тепер вона сидить навпроти тебе з чашкою чаю і спокійно каже: «Дивись, насправді все не так страшно. Давай я тобі покажу».

**Аудиторія:**
- Самозайняті та підприємці малого бізнесу (основна)
- Наймані працівники (важлива)
- Всі хто починає життя або бізнес в Австрії

- Teal для кнопок, посилань, акцентів

- Агресивний червоний як основний колір
- Холодний корпоративний синій
- Тьмяний сірий як фон
- Більше 2 темних секцій на одній сторінці

## 3. Типографіка

### Шрифти

| Шрифт | Використання | Вага |
|-------|-------------|------|
| **DM Serif Display** | H1, H2, великі заголовки | 400 (Regular) |
| **DM Sans** | Основний текст, UI, кнопки | 400, 500, 600, 700 |
| **Caveat** | Акцентні підписи, підписи засновниць | 400, 600 |

### Розміри (Desktop)

| Елемент | Розмір | Шрифт | Вага |
|---------|--------|-------|------|
| H1 головний | `clamp(32px, 4vw, 52px)` | DM Serif Display | 400 |
| H2 секція | `clamp(24px, 3vw, 42px)` | DM Serif Display | 400 |
| H3 підсекція | `clamp(18px, 2vw, 28px)` | DM Serif Display | 400 |
| Body large | `17–20px` | DM Sans | 400 |
| Body normal | `14–15px` | DM Sans | 400 |
| Body small | `12–13px` | DM Sans | 400 |
| Caption | `10–11px` | DM Sans | 600–700, UPPERCASE |
| Button | `13–16px` | DM Sans | 700–800 |

### Правила типографіки

- Letter-spacing для UPPERCASE labels: `1.5–2px`
- Line-height для body тексту: `1.75–1.85`
- Line-height для заголовків: `1.15–1.3`
- Заголовки DM Serif: letter-spacing `-0.5px` до `-1px`

## 5. Компоненти

### Кнопки

**Primary (основна):**
```css
background: #038390
color: #ffffff
border-radius: 10–14px
padding: 12–16px 24–36px
font-weight: 700–800
hover: background: #026B76 + translateY(-2px) + shadow
```

**Ghost (контурна):**
```css
background: transparent або #F0F7F8
border: 1px solid rgba(3,131,144,0.25)
color: #038390 або #595959
hover: border-color: #038390, color: #038390
```

**Link button:**
```css
color: #038390
font-weight: 600
text-decoration: none
hover: text-decoration: underline
```

### Картки

**"QLIXA" стиль (основний):**
```css
background: #F0F7F8
border-radius: 16–20px
border: 1px solid rgba(3,131,144,0.10)
hover: translateY(-4px) + box-shadow: 0 12px 32px rgba(3,131,144,0.12)
```

**Біла картка:**
```css
background: #ffffff
border: 1px solid #E6F4F5
border-radius: 14–16px
box-shadow: 0 4px 16px rgba(53,52,52,0.07)
```

**Акцентна (темна) — використовувати рідко:**
```css
background: #1A1A1A
border-radius: 16–20px
color: #ffffff
```

### Badges / Labels
```css
font-size: 11px
font-weight: 700
letter-spacing: 2px
text-transform: uppercase
padding: 4–6px 12–16px
border-radius: 999px
background: rgba(3,131,144,0.1)
border: 1px solid rgba(3,131,144,0.25)
color: #038390
```

### Розділювачі секцій
```css
HRFlowable / border-top: 1px solid #E6F4F5
Не використовувати темні або товсті лінії
```

## 6. Зображення та ілюстрації

### Стилі по контексту

| Контекст | Стиль |
|---------|-------|
| "Про нас", особисті історії | Теплі мальовані портрети |
| "Це знайоме?", болі | М'які мальовані ілюстрації |
| Функції платформи | Мінімалістичні SVG іконки |
| Скріншоти платформи | Обережно, не перевантажувати |
| Статті cover | Фото + типографіка або чисте фото |

### Правила зображень
- Завжди: `objectFit: cover`, `objectPosition: center 35%`
- Ілюстрації: без фону (PNG), теплі кольори
- Іконки: однаковий стиль в межах секції
- Emoji: тільки в бегучій строці та дрібних акцентах

## 7. Тон голосу

### Можна
- Писати "ти" (не "Ви")
- Легкий жарт (без клоунади)
- Емодзі (1–2 на блок, не в кожному реченні)
- Теплий, підтримуючий тон
- Прості речення без складних термінів

### Не можна
- Сарказм
- Занадто "прикольні" фрази коли мова про податки
- Дитячий тон
- Складні бухгалтерські терміни без пояснення
- Гарантії або юридичні твердження

### Приклади правильного тону
✅ "Дивись, насправді все не так страшно. Давай я тобі покажу."
✅ "Ми теж проходили цей шлях."
✅ "Без паніки — ми вже все розрахували за тебе."

❌ "Оптимізуйте свої податкові зобов'язання!"
❌ "ТЕРМІНОВО! Зареєструйтесь зараз!"
❌ "Ви зобов'язані подати декларацію."

## 8. PDF документи (фірмовий стиль)

Всі PDF що генеруються на сайті мають дотримуватись:

**Хедер:**
- Білий фон
- Логотип `logo-name-slogan_planets_black.svg` зліва
- Teal лінія знизу `#038390`, товщина 2px
- Назва документу справа, `qlixa.eu`

**Футер:**
- Білий фон
- Логотип зліва (менший)
- "Твій цифровий бізнес-помічник в Австрії | qlixa.eu" справа
- Лінія зверху `#E6F4F5`

**Кольори в PDF:**
- Заголовки секцій: teal фон `#038390`, білий текст
- Рядки: чергуються `#F0F7F8` / `#FFFFFF`
- Акцент "успіх": `#E8F8F0`
- Акцент "увага": `#FFF8E7`
- Дисклеймер: курсив, `#888888`

## 9. Правила для нових сторінок і секцій

При додаванні нової сторінки, секції або статті:

### Обов'язково перевірити:
1. Фон — Powder `#F0F7F8` або White `#FFFFFF` (не темний)
2. Шрифти — тільки DM Serif Display + DM Sans + Caveat
3. Кольори — тільки з палітри вище
4. Відступи — відповідають таблиці вище
5. Тон — дружній, простий, без жаргону
6. Повітря — достатньо відступів між блоками

### Структура нової статті:
- Hero: заголовок + підзаголовок + теги + дата + час читання
- TOC sidebar (для довгих статей)
- Зміст з якорями
- Disclaimer якщо є юридична інформація
- CTA в кінці

### Структура нової секції на головній:
- Badge "UPPERCASE LABEL" teal
- H2 заголовок DM Serif
- Підзаголовок DM Sans gray
- Контент
- CTA кнопка (якщо потрібна)

## 11. "Заборонено" в дизайні

- ❌ Забагато анімацій (тільки subtle hover)
- ❌ Порожні сторінки без повітря
- ❌ Корпоративний стиль (сірі блоки, жорсткі лінії)
- ❌ Яскраві кричущі кольори
- ❌ Більше 1 темної секції на сторінку
- ❌ Emoji як основні іконки в секціях
- ❌ Таблиці "як в Excel"
- ❌ Текст без відступів між абзацами

| Фон секції | Текст | Логотип |

## 14. Правила поведінки при редагуванні

- Перед будь-якою зміною — спочатку питай дозволу
- Не змінюй висоту секцій та розміщення карток
- Якщо просять замінити текст — міняй ТІЛЬКИ вказаний текст, не перефразовуй
- Якщо питання про дизайн і є невпевненість — пропонуй 2–3 варіанти
- Нова стаття = ті самі параметри що й існуючі (уточни перед додаванням)
